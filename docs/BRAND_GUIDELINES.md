# KronShield — Intelligent Cybersecurity

KronShield es el producto open source de BLANDSKRON para gestionar autorizaciones, revisar el alcance y conservar evidencia de auditorías. La marca expresa protección, inteligencia verificable y control del usuario.

| Elemento | Escritura oficial |
|---|---|
| Nombre | KronShield |
| Descriptor | Intelligent Cybersecurity |
| Eslogan | Intelligent Security. Responsible by Design. |
| Firma | Open Source · By BLANDSKRON |

En texto corrido se usa **KronShield**. Para portadas, metadatos y primera mención institucional se usa **KronShield — Intelligent Cybersecurity**. La interfaz utiliza español para las tareas, los estados y los mensajes de error. Conserva las frases oficiales en inglés.

## Identidad visual

El escudo de seis esquinas combina un contorno de protección y una K geométrica de un solo trazo visual. La transición azul–turquesa enfatiza análisis y protección. La retícula del paisaje del escudo sugiere inspección y contexto. Es decorativa y carece de significado operativo.

| Recurso | Uso |
|---|---|
| [Composición horizontal](../frontend/src/assets/kronshield-lockup.svg) | README, portadas y presentación institucional. Ideal desde 190 px de ancho. Usa texto SVG con Sora e Inter como fuentes preferidas. |
| [Isotipo a color](../frontend/src/assets/kronshield-mark.svg) | Barra de marca y aplicaciones principales. Usa 32 px o más en interfaz y conserva un cuarto de su ancho como espacio libre alrededor. |
| [Isotipo monocromático](../frontend/src/assets/kronshield-mono.svg) | Impresión y aplicaciones de un color. Usa `currentColor` cuando insertes el SVG en línea y elige una tinta que contraste con el fondo. |
| [Favicon](../frontend/src/assets/kronshield-favicon.svg) | Pestañas a 16–32 px. El escudo simplificado aumenta el grosor relativo de su borde y conserva la K. |
| [Paisaje del escudo](../frontend/src/assets/kronshield-field.svg) | Fondo editorial de acceso y del panel principal. En ambos puntos se presenta con texto alternativo vacío. |

Mantén la proporción del escudo, evita sombras encima de la K y reserva el degradado para la marca y las áreas editoriales. En interfaces de trabajo, el texto, las superficies y el foco usan los tokens semánticos. [Sistema de diseño](DESIGN_SYSTEM.md)

## Relación con BLANDSKRON

La web corporativa y su código usan violeta `#4A148C`, morado profundo `#2E0B59`, acento `#8B5CF6`, Inter para lectura, Manrope para titulares y JetBrains Mono para etiquetas técnicas. La referencia combina marcos oscuros con superficies claras, esquinas de 21 y 11 px, y foco destacado. KronShield conserva Inter, JetBrains Mono, la estructura geométrica y el acento violeta como referencia familiar. El escudo, la paleta turquesa y Sora distinguen al producto. [BLANDSKRON](https://blandskron.cl/) · [Tokens corporativos, revisión 4da2ef2](https://github.com/Blandskron/blandskronSPA/blob/4da2ef20d200cfbc08fffd332bcb7674628e8d84/src/styles/tokens.css)

Los nombres técnicos `pentest-agent`, `PENTEST_AGENT_*` y los identificadores de API conservan su compatibilidad. Los informes HTML históricos mantienen su contenido y sus bytes registrados.
